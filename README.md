# StockFlow: Controle de estoque de veículos

Projeto desenvolvido como Trabalho de Conclusão de Curso (TCC), apresentado e avaliado por banca examinadora.

## 📌 Sistema

O StockFlow é um sistema web para controle e visualização de estoque de veículos, desenvolvido com foco em organização de dados e integração backend–frontend.
O sistema permite a listagem dinâmica de veículos e marcas, visualização detalhada individual e navegação entre páginas públicas antes do login administrativo.

## Atuação Técnica

Atuei diretamente no desenvolvimento frontend e backend das telas públicas do sistema.

- Implementação da lógica de listagem dinâmica de veículos e marcas
- Participação na definição da estrutura inicial do banco de dados
- Modelagem inicial das tabelas e organização das entidades do sistema
- Implementação de filtros e tratamento de parâmetros
- Implementação da lógica de imagens
- Implementação de redirecionamento para contato via WhatsApp
- Integração com banco de dados MySQL (bdstockflow)
- Consultas SQL para exibição individual por ID
- Organização da comunicação entre frontend e backend
- Renderização de dados vindos do banco

🔹 Frontend

Desenvolvimento completo da tela inicial com cards dinâmicos;
Implementação da página de detalhes do veículo;
Implementação da página de detalhes da marca;
Criação das telas pré-login;
Estruturação de layout responsivo;
Integração visual com dados dinâmicos do backend.

## Funcionalidades

- Listagem de veículos em formato de cards
- Visualização detalhada de cada veículo
- Visualização detalhada de cada marca
- Contato direto com o estabelecimento através do sistema
- Navegação entre páginas
- Estrutura backend para conexão com banco de dados
- Interface responsiva e organizada

## Como Executar

1. Copie a pasta para `C:\xampp\htdocs\`
2. Inicie Apache e MySQL no XAMPP
3. Importe `bdstockflow` no phpMyAdmin
4. Acesse: `http://localhost/NomeDaPasta`
